Qué se hizo

  1. Migración a SQLite: modelo Estudiante (ORM) y capa de servicio View → Service → Model → BD.
  2. CRUD de personas: crear, listar con búsqueda, editar y eliminar con confirmación.
  3. Túnel: URL pública hacia el servidor local.
OperaciónRuta
